# 모델 구성·워크플로·라이선스·무검열 관련 확인 (2026-10-15 기준)

실행 경로: **ComfyUI v0.43.0** (모든 모델 네이티브 지원, Comfy-Org 공식 템플릿 0.11.97 기준. 2026-10-30 v0.40.0에서 업그레이드 후 전 모델 재검증) + 자체 한국어 GUI(`app\`).

### 변형 선택 이유
- **Anima**: Turbo v1.1(8~12스텝, CFG 1)을 기본, Aesthetic v1.1(30스텝, CFG 4.5, 네거티브 사용)을 고품질로. Base는 LoRA 학습용이라 제외. preview/v1.0 계열 등 구버전 미설치. 2B BF16이 8GB에 들어가므로 양자화 불필요.
- **Krea 2**: Turbo만 설치. RAW는 52스텝+CFG(조건부·비조건부 2회 계산)라 13B 모델을 8GB에서 돌리면 1장 수 분 이상 예상 → 미설치. BF16(26GB) 대신 INT8 ConvRot(공식 Int8 템플릿 사용 형식). RTX 4060 Ti(sm_89)에서 `torch._int_mm` 동작 확인. NVFP4/MXFP8은 Blackwell 전용(이 GPU에서는 에뮬레이션)이라 제외.
- **Qwen-Image 2.1**: Turbo(8스텝 고정 시그마) 기본 + Base(25~40스텝) 고품질. 둘 다 INT8 ConvRot. 텍스트 인코더도 INT8(9.35GB, BF16 17.5GB 대신). W4A8 변형은 품질 검증 자료가 없어 공식 템플릿 기본값인 INT8 선택.
- **설치하지 않은 것**: Qwen 프롬프트 보강 모델(Qwen3.5 9B PE T2I/I2I, 각 9.5GB) — 선택 기능이고 8GB GPU에서 추가 대기 시간이 커서 기본 설치에서 제외. 대신 이미 설치된 Krea 2 텍스트 인코더로 로컬 번역/보강을 제공. Qwen ControlNet, Krea 스타일 LoRA 9종 미설치.

## 2. 모델별 T2I / I2I 지원 (앱 구현 = 공식 템플릿 구조)

| 기능 | Anima | Krea 2 | Qwen-Image 2.1 |
|---|---|---|---|
| T2I | ✅ KSampler (er_sde/simple) | ✅ KSampler 8스텝, 네거티브=ConditioningZeroOut | ✅ Turbo: ManualSigmas 8스텝+SamplerCustomAdvanced / Base: KSampler. `QwenImage21Cache` 사용 |
| 일반 이미지 변환(denoise) | ✅ VAEEncode + denoise | ✅ VAEEncode + denoise | ✅ VAEEncode + denoise (Turbo는 SplitSigmasDenoise). 내용 변경은 약함(실측) |
| 지시문 편집 | ❌ 모델이 T2I 전용, 공식 편집 가중치 없음 | ❌ 공개 RAW/Turbo는 T2I 모델, 공식 편집 모델 없음 | ✅ 공식 경로(`TextEncodeQwenImage21` images, 캔버스=1번 이미지) |
| 참조 조건부 생성 | ❌ 공식 인물·스타일 참조 어댑터 없음(Comfy-Org/Anima-LLLite는 깊이·선화 제어·인페인팅용) | ✅ 화풍 참조: 공식 템플릿의 style reference LoRA + `TextEncodeQwenImageEditPlus` + `FluxKontextMultiReferenceLatentMethod` | ✅ 다중 참조(앱은 3장, 모델은 최대 10장): 프롬프트에서 `<image1>` 등으로 지칭, 캔버스=지정 크기 |

- 입력 이미지를 무시하거나 캡션만 뽑아 T2I로 돌리는 방식은 사용하지 않았습니다. 모든 I2I는 입력 이미지가 VAE 잠재공간 또는 참조 토큰으로 직접 들어갑니다.
- 해상도: Anima·Krea 16의 배수, Qwen 32의 배수로 서버에서 자동 보정, 범위 Anima 512~1536, Krea 768~2048, Qwen 512~2048.

## 3. 메모리 설정 (RTX 4060 Ti 8GB·RAM 32GB PC 실측 근거)

- ComfyUI 기본 **DynamicVRAM**(comfy-aimdo) 유지: `--disable-dynamic-vram`(첫 실행 521초 정체), `--gpu-only`(첫 실행 973초 정체)는 이 PC에서 VRAM 초과분이 드라이버 공유 메모리로 넘어가 채택하지 않음.
- **`--disable-pinned-memory` 채택**: Krea 2에서 핀 메모리 사용 시 엔진 RAM 18.5GB, 시스템 여유 RAM 2.0GB까지 하락(1회 171초). 끄면 엔진 RAM 2.3GB, 여유 17.6GB, 속도 비슷.
- **Krea 2·Qwen은 타일 VAE 디코딩(512px)**: 모델 전환 직후 일반 디코딩이 5분 이상 정체되는 현상을 재현·해결(타일 적용 후 4~5초).
- **한 번에 한 모델만**: 모델 계열 또는 변형이 바뀌면 `/free`(unload_models+free_memory)로 이전 모델을 해제한 뒤 로드.
- `--preview-method none`, 엔진은 `127.0.0.1`에만 바인딩. 공유 링크 없음.

- Stability AI 공식 SD 3.5 저장소는 Hugging Face 로그인·약관 동의(gated)가 필요해, 로그인 없이 받을 수 있는 Comfy-Org 공식 재패키징본을 사용했습니다. 라이선스는 원본과 같습니다(연매출 100만 달러 미만 상업 사용 가능, 이용 정책 준수).
- 사용자 체크포인트: `models\checkpoints`의 `.safetensors` 머리말(텐서 이름)만 읽어 SDXL(`conditioner.embedders.1`)·SD1.5(`cond_stage_model.transformer`)를 구분합니다(`app\model_scan.py`). SD2.x·Flux·SDXL Refiner·SD3 계열 외부 파일은 SDXL 목록에서 제외됩니다.
- LoRA: `models\loras`의 파일을 같은 방식(머리말 키 이름·크기)으로 SDXL/SD1.5/SD3/Anima/Krea 2/Qwen-Image 2.1/Qwen-Image 1.x/Flux.1로 분류해 맞는 모델에서만 보여 줍니다(판별 불가 파일은 모두에 표시). LoRA는 모든 모델에서 쓸 수 있으며(최대 3개), Anima·SDXL·SD1.5·SD 3.5는 `LoraLoader`(모델+텍스트 인코더), Krea 2·Qwen-Image 2.1은 `LoraLoaderModelOnly`(모델만)로 로더 바로 뒤에 적용합니다. 계열별 선언은 `app\models_config.py`의 `"lora"`·`"lora_archs"`.
- Anima LoRA: kohya(`lora_unet_blocks_…`, `lora_te_…`)·일반(`diffusion_model.blocks.…`) 형식을 키 이름으로 판별합니다. `UNETLoader`·`CLIPLoader` 뒤에 `LoraLoader`(최대 3개)를 이어 DiT와 Qwen3 텍스트 인코더 양쪽에 같은 강도로 적용합니다. Anima Base로 학습된 LoRA는 Turbo/Aesthetic에도 적용되지만 효과는 LoRA마다 다를 수 있습니다.

### 구현 (ComfyUI 기본 노드만 사용)

| 기능 | SDXL·SD1.5 | SD 3.5 |
|---|---|---|
| T2I | CheckpointLoaderSimple → (LoraLoader×최대 3) → CLIPTextEncode → KSampler(EmptyLatentImage) | 같은 구조, EmptySD3LatentImage |
| 이미지 변환 | VAEEncodeTiled + KSampler denoise | 같음 |
| 인페인팅 | 마스크(브러시) → ImageToMask → ThresholdMask → GrowMask(8px) → DifferentialDiffusion + VAEEncodeTiled + SetLatentNoiseMask → KSampler → ImageCompositeMasked(마스크 밖 원본 유지) | 같음 |
| 지시문 편집·참조 | 미지원(InstructPix2Pix·IP-Adapter 등 별도 모델 필요) | 미지원 |
| 기본값 | 25스텝, CFG 6.0, dpmpp_2m/karras, 1024²(SD1.5는 512×768) | Medium 30스텝 CFG 4.5, Large 28스텝 CFG 3.5, euler/sgm_uniform(모델 카드·공식 템플릿 기준) |

- 일반(비 인페인팅 전용) 체크포인트에 대해 InpaintModelConditioning(noise_mask) 대신 `VAEEncodeTiled + SetLatentNoiseMask`를 씁니다. 결과는 같은 방식이며, 타일 인코딩으로 SDXL VAE 인코딩 정체를 피하기 위한 선택입니다.
- 인페인팅은 기존 세 모델(Anima·Krea 2·Qwen)에는 연결하지 않았고, GUI에 미지원 사유를 표시합니다.

## 9. MOSS-Image 추가 (2026-10-30, ComfyUI v0.43.0)

ComfyUI 0.42.0부터 MOSS-Image(`CLIPLoader` type `moss_image`, `EmptyFlux2LatentImage`)를 네이티브 지원해 ComfyUI를 v0.40.0 → **v0.43.0**으로 올리고 SFT 모델만 추가했습니다. 모델 계열 ID는 `moss`(CLI `-f moss`).

### 설치 파일 (Comfy-Org/MOSS-Image @530a4c94, SHA256 = Hugging Face LFS 값과 일치 → `model_hashes.md`)

| 역할 | 파일 | 크기 | 정밀도 |
|---|---|---|---|
| 본체(SFT) | `diffusion_models\moss_image_sft_int8_convrot.safetensors` | 5.41GB | INT8(ConvRot) — 원본 OpenMOSS-Team/MOSS-Image-SFT (약 5.1B) |
| 텍스트 인코더 | `text_encoders\qwen3.5_9b_w4a8_gptq.safetensors` | 7.34GB | W4A8 GPTQ (Qwen3.5 9B) |
| VAE | `vae\flux2-vae_small.safetensors` | 0.25GB | Flux.2 VAE (small) |

- **SFT만 설치**: Base는 미세조정·연구용(공식 권장 50스텝·CFG 3)이라 제외. 편집 LoRA·컬러/깊이 제어 LoRA도 전용 노드가 필요해 미설치.
- **INT8 ConvRot 본체**: BF16(10.2GB) 대신 공식 저장소의 INT8(5.4GB).
- **텍스트 인코더 W4A8 GPTQ**: INT8 ConvRot(9.75GB)·BF16(19.3GB) 대신 가장 작은 공식 파일. 이 PC(RTX 4060 Ti, Ada)에서 ComfyUI 로그에 `asym_w4a8_int8`이 네이티브 연산으로 표시되고 생성이 정상이어서 INT8 대체 파일은 받지 않았습니다.
- 라이선스: **Apache-2.0**(상업 사용 가능, 라이선스·고지 유지).
