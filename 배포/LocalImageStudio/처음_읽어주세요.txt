로컬 이미지 생성기 (Anima · Krea 2 · Qwen-Image 2.1 · MOSS-Image · Stable Diffusion SDXL/SD1.5/SD 3.5)
====================================================

내 PC에서만 돌아가는 이미지 생성 프로그램입니다. 프롬프트와 이미지는 인터넷으로 보내지지 않습니다.
(설치할 때만 프로그램과 모델 파일을 인터넷에서 내려받습니다.)

[필요한 환경]
- Windows 10/11 64비트
- NVIDIA 그래픽카드 (VRAM 8GB 이상 권장), 최신 NVIDIA 드라이버 (CUDA 13.0 이상 지원)
  * AMD/Intel 그래픽, Mac은 지원하지 않습니다.
- RAM 16GB 이상 (Krea 2를 쓰려면 32GB 권장)
- 디스크 여유 공간: 프로그램 약 8GB + 모델
    Anima 약 9.8GB / Krea 2 약 19.5GB / Qwen-Image 2.1 약 17.3GB / Qwen Base(선택) 약 7.3GB
    SDXL 약 7.0GB / SD 3.5 Medium 약 11.6GB / SD 3.5 Large 약 14.9GB / MOSS-Image 약 13.0GB
    (원하는 것만 골라 설치)
  * SSD에 두는 것을 권장합니다.

[설치]
1. 이 zip을 공간이 넉넉한 드라이브에 압축 해제합니다. (예: D:\LocalImageStudio)
   - 설치 후 폴더를 옮겨도 되지만, 옮긴 뒤에는 바로가기를 새로 만들어야 하므로 '설치.bat'을 한 번 더 실행하세요.
2. 폴더 안의 '설치.bat'을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 '추가 정보' → '실행'을 누르세요.
3. 안내에 따라 설치할 모델 번호를 고르고(엔터 = 1,2,3 / all = 전부), 라이선스 안내를 확인한 뒤 y를 입력합니다.
   - 나중에 모델을 더 받고 싶으면 '설치.bat'을 다시 실행해 번호를 고르면 됩니다.
4. 다운로드에는 인터넷 속도에 따라 30분~수 시간이 걸립니다.
   중간에 끊기거나 창을 닫아도 '설치.bat'을 다시 실행하면 이어받습니다.
5. 끝나면 바탕화면에 '로컬 이미지 생성기' 바로가기가 생깁니다.

[이전 버전에서 업데이트하기 (v1.2.x 이하 → v1.3.0)]
  1. 바탕화면 '로컬 이미지 생성기 - 종료·복구'로 프로그램을 끕니다.
  2. 새 zip을 기존 설치 폴더에 그대로 덮어쓰기로 압축 해제합니다.
  3. '설치.bat'을 다시 실행합니다.
     - ComfyUI가 이전 버전(예: 0.40.0)이면 v0.43.0으로 자동 교체하고 패키지 버전도 다시 맞춥니다.
       기존 폴더는 잠시 'ComfyUI_old_버전' 이름으로 옮겨 두었다가 설치가 끝나면 정리합니다.
     - 모델(models\), 생성한 이미지(outputs\), 생성 기록·설정(app\data\)은 건드리지 않습니다.
       ComfyUI 안의 입력 이미지·사용자 설정·직접 추가한 커스텀 노드도 새 ComfyUI로 옮겨 줍니다.
     - 이미 받은 모델은 다시 받지 않습니다. 새 모델(MOSS-Image 등)은 번호를 골라 추가하세요.
  - '설치.bat'을 다시 실행하지 않고 실행하면 "ComfyUI가 오래되었습니다" 안내가 나옵니다.
  v1.3.0 바뀐 점: MOSS-Image 모델 추가(ComfyUI 0.43.0), 모든 모델에서 LoRA 사용,
                  생성 기록 페이지 넘김·여러 개 선택 삭제, 업스케일 기능 제거
                  SD 3.5 LoRA를 Medium용·Large용으로 구분해 고른 변형에 맞는 것만 표시

[이미 받은 모델은 다시 받지 않습니다]
  - 모델 선택 화면에 [설치됨] / [일부 설치됨] 이 표시되고, 이미 있는 파일은 무결성(SHA256)만 확인하고 건너뜁니다.
  - 이 폴더에 없는 모델은 먼저 PC 안에서 찾아봅니다(최대 약 2분):
    다른 ComfyUI 설치 폴더, 예전에 설치한 LocalImageStudio 폴더, Hugging Face 캐시 등에서
    같은 이름·같은 크기의 파일을 찾으면 목록을 보여 주고, 확인(Y)하면 다운로드 대신 사용합니다.
    같은 드라이브면 하드링크(추가 공간 거의 없음), 다른 드라이브면 복사합니다.
  - USB 등에 받아 둔 모델 폴더가 있으면 설치 중 "모델 폴더 경로 입력"에 그 경로를 넣으세요.
  - 찾은 파일도 SHA256이 공식 값과 다르면 쓰지 않고 인터넷에서 새로 받습니다.

[실행]
- 바탕화면 '로컬 이미지 생성기' (또는 폴더의 '이미지생성기_실행.bat')
- 검은 창이 뜨고 약 20초 뒤 브라우저에 화면이 열립니다. 검은 창을 닫으면 종료됩니다.
- 멈췄을 때: 바탕화면 '로컬 이미지 생성기 - 종료·복구' 실행 후 다시 실행.

[내 Stable Diffusion 모델·LoRA 쓰기]
- Civitai 등에서 받은 SDXL·SD1.5 체크포인트(.safetensors, Illustrious·Pony 포함) → models\checkpoints 폴더에 넣기
- LoRA(.safetensors) → models\loras 폴더에 넣기 (SDXL·SD1.5·SD3.5·Anima·Krea 2·Qwen-Image 2.1용 LoRA 모두 같은 폴더)
- 앱 화면을 새로고침하면 체크포인트는 'Stable Diffusion (SDXL·SD1.5)'의 모델 변형 목록에,
  LoRA는 그 LoRA에 맞는 모델을 골랐을 때 LoRA 칸에 나타납니다(모든 모델에서 사용 가능, 최대 3개).
  Anima·SD 계열 LoRA는 모델과 텍스트 인코더에, Krea 2·Qwen-Image 2.1 LoRA는 모델에만 적용됩니다.
  (SDXL을 설치하지 않아도 직접 넣은 체크포인트만으로 사용할 수 있습니다.)
- 부분 수정(인페인팅): 이미지 위에 고칠 곳을 브러시로 칠하면 그 부분만 다시 그립니다(SD 계열 전용).

[폴더 구성 (설치 후)]
  app\        프로그램 소스
  setup\      설치 프로그램
  docs\       설명서
  python\  venv\  ComfyUI\  tools\   설치 때 자동으로 생김

  logs\       실행 기록
